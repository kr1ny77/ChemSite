# ChemSite human character candidate

The candidate in `artifacts/character-candidate/` is built with Blender 5.2.2,
MakeHuman Community MPFB 2.0.17, and the official MakeHuman system assets pack.
The MPFB extension archive SHA-256 is
`4f0a879d64a39bf646fbf5f53601ac678855da329d650617dca5737548239a87`.
The system assets archive SHA-256 is
`b542127a8e25547c7c29c19f2d1d2adb9a664c80396ecd694095dbc8028a0107`.

The character uses `young_caucasian_male` skin, `male_worksuit01` clothing,
`shoes06`, `low-poly` eyes, and `eyebrow001`. These are official CC0 graphical
assets. MPFB's GPL/AGPL code runs only as an authoring tool. The custom hardhat
geometry is generated by `build_realistic_chemist.py` and belongs to ChemSite.
Sources: https://static.makehumancommunity.org/about/license.html and
https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html.

The current candidate is a proportionate human mesh with a 53-bone game-engine
rig, but has no animation actions. Keep the existing playable character until
Idle, Walk, Run, Turn, Interact, PickUp, UseStation, Celebrate, and Failure are
authored, exported, and checked in Godot. Verify front, side, rear, and three
quarter renders, foot contact, held poses, and isometric in-game readability.

The official worksuit texture has a blue camouflage pattern. This is a visual
quality issue to resolve before final character acceptance. The first safety
vest prototype produced planar and jagged panels, so it was removed from the
candidate generator pending a properly tailored mesh.
