# ChemSite v0.1.0

First native desktop prerelease of ChemSite, a single-player educational chemistry
game for first-year Construction and Civil Engineering students. Interface and
chemistry content are in Russian. All experiments are virtual.

## Included

- Five career levels with 200 curated tasks and deterministic answer validation.
- Untimed practice across all 44 level/topic pairs.
- Formula assembly, equation entry, numerical calculations, virtual measurements,
  reagent observations, electrochemistry/corrosion comparisons and construction missions.
- Original cartoon construction student, enclosed yard, target-station marker,
  eight optional inspections and earned construction stages.
- Local progression, topic learning, score/combo/stars, keyboard UI, audio settings,
  reduced motion and focus-loss pause.

## Downloads

- **ChemSite-macOS.zip** — universal Intel/Apple Silicon application.
- **ChemSite-Windows.zip** — Windows x86_64 EXE and matching PCK.
- Matching `.zip.sha256` files contain download checksums.

Extract the entire archive. On Windows, keep `ChemSite.exe` and `ChemSite.pck`
together. On macOS, open `ChemSite.app`; the build is unsigned/unnotarized and
may require explicit approval in Privacy & Security. Each archive includes
installation instructions, build metadata, asset credits and third-party notices.

Movement: WASD/arrows. Interaction: E. Run: Shift. Pause/back: Escape.
Keyboard UI: Tab/Shift+Tab and Space/Enter. Audio and motion options are in Settings.

## Verification and remaining acceptance

Automated evidence covers native exports, five-level career rounds, all-level
practice/save isolation, keyboard gameplay, content/layout checks, settings,
reduced motion and graphical UI captures. Build-specific workflow links and
archive checksums accompany publication.

This prerelease remains under broader testing. Human movement/audio/accessibility
acceptance, physical Windows input/audio/save checks, approximately 60 FPS on a
representative student laptop and a target-course instructor review remain open.
Tight turns/reversals retain bounded foot drift. Windows hosted graphical QA uses
Compatibility rendering; physical Windows Forward+ acceptance remains open.

Please retain the included `BUILD_INFO.json` when reporting an issue so reports
can identify the source revision and platform.
