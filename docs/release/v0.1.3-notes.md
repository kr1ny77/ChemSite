# ChemSite v0.1.3 — подсказки по запросу

## Изменения

Подсказка скрыта при открытии задания. Кнопка «ПОКАЗАТЬ ПОДСКАЗКУ»
в правом верхнем углу карточки раскрывает её; «СКРЫТЬ ПОДСКАЗКУ»
сворачивает текст. Кнопка доступна с клавиатуры через Tab и Space/Enter.
Каждое открытие задания начинает со скрытой подсказки.

Варианты ответов перемешиваются отдельным случайным порядком для каждого
задания. Повторное открытие той же карточки сохраняет порядок в этой смене.

В базе 200 заданий на пяти уровнях, 44 темы практики. Все опыты виртуальные.

## Установка Windows

Скачайте `ChemSite-Windows.zip`, выберите «Извлечь всё…», откройте
папку ChemSite и запустите `ChemSite.exe`. Сохраняйте рядом `ChemSite.pck`.
Всё игровое содержимое включено; версия для Windows x86_64.
WASD/стрелки — движение, Shift — бег, E — взаимодействие,
Escape — пауза/назад, Tab и Space/Enter — меню.

## Проверки и ограничения

Исходный код: `fea5dda2c6540ee7467e885e7b294b73e713f093`.
Версии: macOS 0.1.3, Windows 0.1.3.0.
Native macOS: 200 заданий с закрытой/открытой подсказкой и расширенными
наблюдениями, 400 экранов обратной связи, 11 317 проверок контраста/состояний;
раскрытие через Space, сохранение фокуса и сброс нового задания проверены.
Готовое приложение прошло смену с клавиатуры и практику на пяти уровнях.

macOS-приложение универсальное для Intel/Apple Silicon, без подписи
и нотариального заверения. Пользователь проверяет свой Windows-компьютер
самостоятельно. Остаются расширенная проверка доступности, рецензия
преподавателя и полировка контакта стоп в резких разворотах.
Графическая проверка Windows в CI использует Compatibility.
