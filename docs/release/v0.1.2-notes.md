# ChemSite v0.1.2 — предварительная версия

Одиночная учебная игра по химии на мультяшной строительной площадке.
В базе 200 заданий: пять уровней по 40 заданий, 44 темы для тренировки.
Одна карьерная смена состоит из пяти заданий. Все опыты виртуальные.

## Изменения

- Добавлены цветные угловые метки рабочих зон возле оборудования.
- Проработаны мешки цемента: плоские бумажные грани, складки и закрытые торцы.
- Настроены окрашенный металл каркаса, ограждения, оконные рамы и кровля.
- Сохранены плавное ускорение, указатель нужной станции, тихие шаги и исправленная анимация рукавов из 0.1.1.

## Windows

Скачайте `ChemSite-Windows.zip`, распакуйте весь архив и откройте
`ChemSite/ChemSite.exe`. Файлы EXE и PCK должны лежать вместе.
Версия для Windows x86_64 использует Godot Forward+.

WASD/стрелки — движение, Shift — бег, E — взаимодействие,
Escape — пауза/назад. Tab и Space/Enter — выбор в меню.
Громкость и уменьшение движения доступны в настройках.

## Область проверки

macOS: универсальная сборка для Intel и Apple Silicon; подпись и нотариальное
заверение отсутствуют. Автоматические проверки охватывают управление,
сохранения, задания и режим практики. Пользователь принял пятизаданийный
macOS тест и комфорт шагов. Проверку своего Windows-компьютера пользователь
проводит самостоятельно. Остаются расширенная проверка доступности,
рецензия преподавателя и улучшение контакта стоп при резких разворотах.
Графическая проверка Windows в CI использует Compatibility.
