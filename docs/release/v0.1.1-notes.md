# ChemSite v0.1.1 — candidate notes

Desktop prerelease update for the Russian-language single-player construction
chemistry game. All experiments are virtual.

## Changes

- Added qualitative diagrams to all 32 comparison activities, including kinetics,
  hydrolysis, corrosion and equilibrium. Curated answers and explanations remain
  deterministic across all 200 chemistry tasks.
- Improved Walk/Run transitions by renewing planted-foot anchors when the gait
  changes. Measured 60 Hz reversal displacement decreased from 61.84 to 40.35 mm.
- Replaced footsteps with four quiet brushed-sole variants and rounded attacks.
- Hid navigation prompts while task, feedback and pause cards are open; the
  exploration prompt returns as soon as the card closes.
- Added release/source provenance to packages and aligned embedded application
  versions: macOS 0.1.1, Windows 0.1.1.0.

## Installation

Extract the entire platform archive. On Windows, keep `ChemSite.exe` and
`ChemSite.pck` together. The universal macOS app supports Intel and Apple Silicon.
The macOS build is unsigned and unnotarized; system approval may be required.
Included instructions, credits, notices and `BUILD_INFO.json` describe each build.

Move with WASD/arrows, run with Shift, interact with E, pause/back with Escape.
Use Tab/Shift+Tab and Space/Enter for keyboard menus. Settings provide audio
volume and reduced motion controls.

## Verification scope

The b583a3e platform archives passed native and graphical review. A subsequent
character review found cuff weights attached to lower-body bones. This candidate
is superseded by the sleeve repair; fresh platform builds and replacement draft
assets are required before publication.

Broader acceptance remains open: human movement/audio/accessibility review,
physical Windows Forward+ input/audio/save checks, approximately 60 FPS on a
representative student laptop and target-course instructor review. Tight turns
and reversals retain residual foot displacement. Hosted Windows graphical QA
uses Compatibility rendering.
