# ChemSite: запуск на Windows

## Что понадобится

Windows 10 или 11, 64-разрядная, компьютер Intel/AMD и драйвер видеокарты
с поддержкой Vulkan для Forward+. Браузер и интернет используются для
скачивания; игра работает офлайн. Всё игровое содержимое включено в архив.

## Скачать и открыть

1. Откройте раздел Releases: https://github.com/kr1ny77/ChemSite/releases.
2. В нужном выпуске раскройте Assets и скачайте **ChemSite-Windows.zip**.
3. В «Загрузках» нажмите на ZIP правой кнопкой и выберите **Извлечь всё…**.
4. Выберите удобную папку, например «Рабочий стол → ChemSite».
5. Откройте распакованную папку **ChemSite** и дважды нажмите **ChemSite.exe**.
6. Сохраняйте рядом **ChemSite.pck**. Перемещайте всю папку игры целиком.

Готовая игра запускается самостоятельно. Godot, Blender, Python и инструменты
разработки предназначены для работы с исходным проектом.

## Управление

| Действие | Клавиши |
| --- | --- |
| Двигаться | WASD или стрелки |
| Бежать | Shift |
| Открыть станцию / осмотреть объект | E |
| Пауза / назад | Escape |
| Перейти между кнопками | Tab / Shift+Tab |
| Нажать выбранную кнопку | Space / Enter |

Стрелка указывает станцию для текущего задания. В настройках доступны
громкость музыки/эффектов и уменьшение движения.

## Новое в версии 0.1.4

Подсказка появляется по кнопке «ПОКАЗАТЬ ПОДСКАЗКУ» вверху карточки.
Кнопка «СКРЫТЬ ПОДСКАЗКУ» сворачивает её. Каждое открытие задания
начинается со скрытой подсказки. Варианты ответов перемешиваются;
повторное открытие той же карточки в смене сохраняет порядок.

В базе 1000 заданий и 13 последовательных учебных глав на пяти строительных площадках. В практике можно выбрать одну или несколько тем из 50 пунктов.

Кнопка «МАТЕРИАЛЫ» открывает таблицу Менделеева, справочники, схемы, фотографии и интерактивный черновик. После ответа для 570 расчётных заданий доступно решение по шагам. История ответов карьеры сохраняется между запусками; дальнейшие смены выбирают ещё не решённые задания. Для повторения служит практика.
Карьерная смена состоит из пяти заданий. Все опыты виртуальные.
