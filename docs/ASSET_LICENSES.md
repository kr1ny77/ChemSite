## Music provenance verification — 2026-10-08

The repository contains the original composition source in
`legacy-web/scripts/render-lofi.mjs` (tracked since 60f5652). It defines four
arrangements, MIDI pitches, chord progressions, note envelopes, deterministic
noise percussion and stereo delay directly in code. Audio is synthesized offline
and encoded with FFmpeg; the generator reads no external recordings or samples.

Executed the existing generator from an isolated temporary working directory.
Track 1 regenerated byte-for-byte identically to both the preserved browser asset
and the production native copy: 1,317,243 bytes; SHA-256
`af3f2e358c88af1568ef5b0eb5a025b3ddc6b8a57076d7d1e1839908cbd2d529`.
Evidence: `artifacts/music-provenance-proof.json`. The native track and current
mix retain their existing bytes. This resolves the earlier unspecified music
source entry; human mix listening remains an open audio acceptance requirement.
